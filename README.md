
関数のグラフと式の対応を学べるウェブサイトです。

直線・放物線・双曲線を題材に、「グラフ→式」「式→グラフ」の双方向で学習できます。


🌐 ウェブサイトURL
https://logigritlab.github.io/graph-function-drill_JP

主な機能
•	直線（一次関数）・放物線（二次関数）・双曲線（反比例）のグラフを練習 
•	グラフ → 式 モード 
•	式 → グラフ モード 
•	3択クイズ 
•	即時フィードバック 
•	スコア・連続正解数（ストリーク）の記録 
•	日本語・英語の二言語対応 

学習内容
•	一次関数 
•	二次関数 
•	反比例 


対象ユーザー

•	中学生 
•	高校生 
•	教師・保護者
