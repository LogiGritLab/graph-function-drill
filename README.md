# Graph Function Drill

An interactive web application for practicing the relationship between graphs and equations.

🌐 Live Demo
https://YOUR_USERNAME.github.io/graph-function-drill/

## Features

- Practice linear, quadratic, and hyperbola graphs
- Graph → Formula mode
- Formula → Graph mode
- Three-choice quiz
- Instant feedback
- Score and streak tracking
- Japanese / English bilingual interface

## Topics

- Linear Functions
- Quadratic Functions
- Hyperbolas
- Coordinate Geometry
- Algebra
- Graph Interpretation

## Technologies

- HTML
- CSS
- JavaScript

- Elementary school students
- Middle school students
- High school students
- SAT Math learners
- A Level Mathematics learners
- Teachers and parents
